# TabPals API (Tabpals-Live)

سرور API برنامهٔ [TabPals](https://sharifbabak-ux.github.io/TabPals/) — برنامهٔ آفلاین‌محور تقسیم هزینهٔ گروهی. با این سرور، رویداد (event) مشترک می‌شود: خزانه‌دار رویداد را بارگذاری می‌کند، اعضا را دعوت می‌کند و همهٔ دستگاه‌ها «عملیات» (operation) را از طریق سرور همگام می‌کنند.

## امکانات
- پایگاه‌داده PostgreSQL (مهاجرت‌های SQL در پوشهٔ `migrations/` هنگام راه‌اندازی اجرا می‌شوند)
- احراز هویت دستگاه با توکن (فقط هش SHA-256 ذخیره می‌شود)، دعوت‌نامه با لینک یا کد ۸ کاراکتری (یک‌بارمصرف، منقضی‌شونده، قابل لغو)
- نقش‌ها (مدیر، خزانه‌دار، عضو) و کنترل دسترسی سمت سرور برای هر نوشتن (`src/permissions.js`)
- همگام‌سازی عملیات (idempotent با `op_id`) و پخش زنده با Socket.IO (وب‌سوکت با بازگشت به polling)
- لاگ ممیزی، لغو دستگاه، پاک‌سازی کامل رویداد
- حذف/بازگردانی عضو (تاریخچهٔ مالی حفظ می‌شود)، فهرست دعوت‌نامه‌ها
- رمزنگاری سرتاسری: سرور هرگز کلید رویداد را نمی‌بیند؛ فقط کلید عمومی ECDH دستگاه‌ها و «پاکت کلید» (key envelope) مات را نگه می‌دارد و بین دستگاه‌ها می‌رساند. مقدارهای `enc:v1:…` بدون تغییر ذخیره می‌شوند
- مستندات کامل: [`docs/API.md`](docs/API.md)

## متغیرهای محیطی
| نام | توضیح |
|---|---|
| `DATABASE_URL` | آدرس اتصال PostgreSQL (الزامی) |
| `PORT` | پیش‌فرض `3000` |
| `ALLOWED_ORIGINS` | فهرست originهای مجاز با ویرگول؛ پیش‌فرض `https://sharifbabak-ux.github.io,https://tabpals.ir,https://app.tabpals.ir` |
| `ENABLE_TEST_PAGE` | اگر `true` باشد صفحهٔ تست اتصال قدیمی روی `/` (و namespace سوکت `/test`) فعال می‌شود؛ پیش‌فرض `false` |

## استقرار روی لیارا
1. در پنل لیارا یک **پایگاه‌داده PostgreSQL** بسازید و آن را به برنامه وصل کنید.
2. یک برنامهٔ **Node.js** با نام `tabpals-api` بسازید و این مخزن را از GitHub متصل کنید (`liara.json`: پلتفرم `node`، پورت `3000`). مرحلهٔ build لازم نیست؛ لیارا `npm install` و `npm start` را اجرا می‌کند.
3. متغیرهای محیطی بالا را تنظیم کنید (`DATABASE_URL` از اطلاعات اتصال پایگاه‌داده). جدول‌ها هنگام اولین اجرا خودکار ساخته می‌شوند.
4. دامنهٔ `api.tabpals.ir` را به برنامه اضافه کنید (رکورد DNS طبق راهنمای لیارا) و گواهی TLS را فعال کنید.
5. `https://api.tabpals.ir/health` باید `{"status":"ok"}` بدهد.

سرور پشت پراکسی لیارا اجرا می‌شود (`trust proxy` فعال است تا محدودیت نرخ بر اساس IP واقعی کار کند).

## اجرا و تست محلی
```bash
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/tabpals npm start

npm test                                   # با pg-mem (حافظه‌ای، بدون نیاز به نصب PostgreSQL)
DATABASE_URL_TEST=postgres://... npm test  # با PostgreSQL واقعی (جدول‌های آن پایگاه‌داده پاک می‌شوند!)
```

در CI (`.github/workflows/test.yml`) برای هر push و pull request هر دو اجرا انجام می‌شود: یک بار با pg-mem و یک بار با کانتینر PostgreSQL 16 واقعی. فایل‌های تست پشت‌سرهم اجرا می‌شوند چون روی یک پایگاه‌داده مشترک کار می‌کنند.

## امنیت
helmet، فهرست سفید CORS، محدودیت حجم بدنه، محدودیت نرخ (کلی، ساخت رویداد، تلاش ناموفق پذیرش دعوت، عملیات هر دستگاه)، SQL پارامتری. لاگ فقط شامل متد، الگوی مسیر، وضعیت و مدت است؛ هرگز بدنهٔ درخواست، توکن یا محتوای عملیات لاگ نمی‌شود.
