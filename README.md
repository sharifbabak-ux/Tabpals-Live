# TabPals-Live

سرور بی‌درنگ (realtime) بسیار کوچک برای [TabPals](https://sharifbabak-ux.github.io/TabPals/) — برنامهٔ آفلاین‌محور تقسیم هزینهٔ گروهی.

**این مرحله فقط یک «تست اتصال» است:** می‌خواهیم ثابت کنیم گوشی‌ها در ایران می‌توانند از طریق این سرور (روی ابر ایرانی لیارا) یک اتاق زندهٔ مشترک داشته باشند. «اتاق سفارش گروهی» واقعی بعداً اضافه می‌شود.

## ویژگی‌ها
- Node.js 20 + Express + Socket.IO (وب‌سوکت با بازگشت خودکار به HTTP long-polling برای شبکه‌های محدود)
- بدون پایگاه داده؛ همهٔ وضعیت در حافظه است
- اتاق با کد ۶ کاراکتری (بدون حروف/ارقام مشابه)، حداکثر ۳۰ عضو
- اتاق ۶ ساعت پس از آخرین فعالیت یا ۳۰ دقیقه پس از خالی شدن حذف می‌شود
- محتوای پیام‌ها هرگز در لاگ نوشته نمی‌شود
- محدودیت حجم بسته (۴ کیلوبایت)، پیام حداکثر ۵۰۰ کاراکتر، حداکثر ۱۰ رویداد در ثانیه برای هر اتصال
- `GET /health` و صفحهٔ تست روی `/`

## استقرار روی لیارا (از GitHub)
1. در پنل لیارا یک برنامهٔ **Node.js** با نام `tabpals-live` بسازید.
2. در بخش اتصال به GitHub، این مخزن و شاخهٔ مورد نظر را انتخاب کنید (فایل `liara.json` در ریشه موجود است: پلتفرم `node`، پورت `3000`).
3. مرحلهٔ build لازم نیست؛ لیارا خودش `npm install` و سپس `npm start` را اجرا می‌کند.
4. آدرس برنامه `https://tabpals-live.liara.run` خواهد بود. `/health` را باز کنید تا `{"status":"ok"}` ببینید.
5. صفحهٔ `/` را روی چند گوشی باز کنید، در یکی اتاق بسازید و با کد در دیگری وارد شوید، سپس «کپی گزارش» را بزنید و نتیجه را در گفتگو بچسبانید.

Originهای مجاز (CORS): `https://sharifbabak-ux.github.io`، `https://tabpals-live.liara.run` و `http://localhost`.

## اجرا و تست محلی
```bash
npm install
npm start        # http://localhost:3000
npm test         # تست خودکار (node:test)
```
